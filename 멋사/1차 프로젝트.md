프론트에서 필요한 API/필드명 정리

1. 로그인
POST /auth/login
{ user_id, pwd }

2. 회원가입
POST /auth/register
{ user_id, user_nm, pwd }

3. 계좌 조회
GET /accounts?userId=test1
응답 필드:
accountNumber, alias, balance, status

DB 매핑:
account_no -> accountNumber
account_nm -> alias
balance -> balance
account_stat -> status

4. 이체
POST /transfer
{ fromAccount, toAccount, amount }

5. 거래내역
GET /transactions?accountNo=계좌번호&status=all|deposit|withdrawal&sort=asc|desc
응답 필드:
id, time, fromAccount, toAccount, amount, status

DB 매핑:
tran_id -> id
tran_dt -> time
frm_account_no -> fromAccount
to_account_no -> toAccount
tran_amt -> amount

status는 기준 계좌가 frm_account_no면 출금, to_account_no면 입금으로 계산
