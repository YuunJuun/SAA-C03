1. 조인
	1) query ( select ) 작업 3가지
		- projection : 컬럼 선택, select 절
		- selection : 레코드 선택, where 절
		- join : 2개 이상의 테이블에서 selection 과 projection 처리

	2) 용도
		- 원하는 데이터가 여러 테이블에 분산되어 있는 경우에
			테이블을 연결(join)해서 데이터를 조회하는 방법

	3) 종류1 (!!!!!!!!!!!!!!!)
		가. inner 조인 ( 일반적으로 의미하는 조인)
		- 테이블간의 연결고리 (데이터가 일치)가 있는 데이터만 출력하는 방식
			즉 일치하지 않으면 누락됨

		나. outer 조인
		- inner 조인 + 누락된 데이터까지 포함해서 출력하는 방식

	4) 종류2
		가. ANSI 조인
		- DBMS 독립적

		나. 비 ANSI 조인
		- DBMS 의존적

	5) 종류3
		가. equi 조인
		- 값이 정확하게 일치하는 방식으로 조인
		- 연산자로 사용하면 등등연산자(=) 사용

		나. non-equi 조인
		- 값이 정확하게 일치하지는 않는 방식으로 조인
		- 연산자로 사용하면 between A and B 사용

2. ANSI 조인
	1) cross 조인
	```sql
	select
	from 테이블명1 cross join 테이블명2;
	```

	동작:
		테이블명1의 하나의 레코드(행)와 테이블명2의 모든 레코드가 연결된다.
		조인된 결과는 데이터로서 사용불가
		최종 레코드는 테이블명1갯수 * 테이블명2갯수 만큼 결과가 출력됨
	
	2) natural 조인

		문법1 :
		```SQL
		SELECT 
		from 테이블명1 natural join 테이블명2;
		```

		문법2:
		```SQL
		SELECT 별칭1 .컬럼, .., 별칭2 .컬럼, ...
		from 테이블명1 별칭1 natural join  테이블명2 별칭2;
		```
		동작: 테이블명1과 테이블명2에 공통컬럼을 찾아서 조인한다.
			만약 공통컬럼이 없으면 조인 불가
			만약 공통컬럼이 2개라면 쌍으로 비교해서 조언
			단점은 어떤 컬럼으로  조인되었는지를 추가로 확인하는 작업이 필요하다

	3) using 절

		문법1 :
		```sql
select
from 테이블명1 [inner] join 테이블명2  using(공통컬럼명);
		```

		문법2:
		```sql
select 별칭 . 컬럼, .....
from 테이블명1 별칭 join 테이블명2 별칭 using(공통컬럼명); -- using 에서는 별칭사용 x
		```

		문법3:
		```sql
select 별칭 . 컬럼 ......
식
where 조건식
		```
		동작:
			테이블명1 과 테이블명2 에서 using에 설정된 공통컬럼으로 조인한다

	4) on 절 (범용적)

		문법:
		```sql
select *
from 테이블 1 [inner] join 테이블2 ON 조건
where 조건;

ex.
select *
from emp join dept on emp.deptno = dept.deptno;

select ename, sal, dname, loc, e.deptno -- 공통컬럼 지정시 반드시 별칭 지정 (emp.deptno)
from emp join e dept d on e.deptno = d.deptno; -- equi 조인
		```

		non-equi 조인
		
		emp 와 salgrade
		````sql
select *
from emp e join salgrade s ON e.sal BETWEEN s.losal AND s.hisal;
		````

		3개 조인
		
		a. natural join
		 ```sql
select *
from t1 natural join t2

select *
from t1 natural join t2
		natural join t3
		 ```

		b. using
		```sql
select *
from t1 join t2 using(공통컬럼)

select *
from t1 join t2 using(공통컬럼)
		join t3 using(공통컬럼)
		```

		c. on
		```sql
select *
from t1 join t2 on 조건식

select *
from t1 join t2 on 조건식1
		join t3 on 조건식2;

-- 사원명, 부서번호, 부서명, sal, sal 등급 출력하시오
select *
from emp e join dept d using(deptno)

select *
from emp e join dept d using(deptno) join salgrade s ON e.sal BETWEEN s.losal AND s.hisal;
		```

3.  Outer 조인
	- 기본적으로 join은 inner 조인임 ( 일치하는 데이터만 출력됨)
		그런데 일치하지 않는 데이터까지 포함해서 조인하는 방식임

	문법:
	```sql
select *
from t1 LEFT OUTER JOIN t2 ON|USING

select *
from t1 RIGHT OUTER JOIN t2 ON|USING
	```
