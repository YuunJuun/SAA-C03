 5. 조건 함수
 https://docs.oracle.com/cd/E17952_01/mysql-8.0-en/flow-control-functions.html

   1) if

     IF(expr1,expr2,expr3): expr1 참이면 expr2
                                  거짓이면 expr3

      SELECT IF(1<2,'yes','no');
        -> 'yes'


   2) case ( 자바의 switch값(동등비교) 또는 다중 if(부등) 문과 비슷 )-ANSI

       가. 동등비교

          
              CASE value WHEN compare_value THEN result 
	                [WHEN compare_value THEN result ...] 
			[ELSE result] 
	      END

	 ex.  job에 따른 실수령 출력

	      CLERK      <== sal * 1.1
	      SALESMAN   <== sal * 1.2
	      MANAGER    <==  sal * 1.3
	      ANALYST     <==  sal * 1.4
	      이외          <== sal
	     
	    출력:
	        empno, ename, job,   sal , 실수령
		--------------------- -------
	                      CLERK   1000  1000*1.1
	                     SALESMAN 1000  1000*1.2

		
		select empno, ename, job, sal , case ~ end as 실수령
		from emp;


       나. 부등비교 

               CASE WHEN condition THEN result 
	           [WHEN condition THEN result ...] 
		   [ELSE result] 
	       END


		ex. sal에 따른 직급출력
	
		 sal > 3000 <== 이사급
                 sal > 2500 <== 과장급
		 이외         <== 사원급

	      empno, ename, job,    sal , 직급
		--------------------- -------
	                      CLERK   4000  이사급
	                     SALESMAN 2800  과장급
			              800   사원급 


	   select empno, ename,job, sal,  case WHEN  sal > 3000 THEN '이사급'
	                                       WHEN  sal > 2500 THEN '과장급'
	                                       ELSE '사원급'
	                                  end as 직급
	   from emp;

7. 그룹함수
https://docs.oracle.com/cd/E17952_01/mysql-8.0-en/aggregate-functions-and-modifiers.html

  1) 함수종류
   
    SUM([DISTINCT] expr)  : 총합
    avg([DISTINCT] expr) : 평균
    max([DISTINCT] expr) : 최대값
    min([DISTINCT] expr) : 최소값
    count([DISTINCT] expr):레코드 갯수, 기본적으로 null 제외하고 카운트됨
    COUNT(*) : 전체레코드 갯수

  2) 그룹함수 적용되는 대상? 
    - 그룹별로 적용됨

  
  3) 그룹별로 만드는 방법

    가. 명시적
	
	select 절
	1번 from 절
	2번 [where 조건식]
	3번 group by 컬럼
	4번 having 조건식
	[order by 절];

	ex.
	    select sum(sal)
	    from emp
	    group by job; // job별
	   
	    group by deptno; //부서별

	
	     select deptno, sum(sal)
	    from emp
	    group by deptno//부서별
	    having sum(sal) > 9000;

      특징:
          - group by 표현식(컬럼명|별칭|위치)  # Oracle에서는 별칭|위치 안됨
	  - select에 일반 컬럼을 사용할려면 반드시 group by로 설정한 컬럼만 사용이 가능하다(*****)
	  - where절에는 그룹함수 사용불가



    나. 묵시적

      - group by로 지정하지 않으면 자동으로 전체 레코드를 가진 하나의 그룹으로 묶음
      

      select 절
      from 절;


            select sum(sal), avg(sal), max(sal), min(sal), count(sal)
	    from emp;
