2. 트랜잭션 (transcation)

	1) 개념:
		1개 이상의 DML 작업들을 논리적으로 하나의 작업으로 묶어서 처리하는 개념으로서, 묶음을 의미

		ex. 
			계좌이체 (A -> B , 500 이체)
					A 계좌에서는 update ( 1000 -> 500 )
					B 계좌에서는 insert ( null -> 500 )

		##현재 상황
		A계좌							B 계좌
		1000

		##성공
		A계좌 				             B계좌
		500					              500

		##실패
		A계좌               			 B계좌
		1000

	2) 트랜잭션 명령어 (TCL, DTL)

		가. commit
		- 트랜잭션이 모두 성공했을 때 실제로 반영하는 명령어

		나. rollback
		- 트랜잭션이 하나라도 실패했을 때 실제로 모든 작업을 취소하는 명령어

	3) 특징
		- 시작~끝 ( 종료 )
		시작은 DML을 사용하면 자동으로 시작됨
		종료는 TCL ( commit, rollback ) 으로 지정

		ex.
    ```
    insert 문 <- 트랜잭션 시작
	commit, rollback <- 트랜잭션 종료
    ```

	4) DBMS마다 트랜잭션 처리방법이 다름
		가. MySQL
		- auto commit으로 처리됨
		따라서 트랜잭션으로 묶을수 없음
		비활성화 시키고 트랜잭션으로 처리 가능

		@@ autocommit 여부 확인
		show variables like 'autocommit%';

		@@ autocomiit 비활성화
		set autocommit=false; 

		나. Oracle
		- 명시적으로 commit/rollback 으로 트랜잭션을 종료해야 됨

3. INSERT 문

	1) 용도
	- 새로운 레코드 생성
	- 단일행 생성 및 다중행 생성

	2) 단일행 생성 방법

		가. 컬럼명 명시 (권장함)

		- 문법:
		    ```sql
							    <-- 트랜잭션 시작
	insert into 테이블명 (컬럼명, 컬럼명2, ...)
				values (값, 값2, ...);
								<-- 트랜잭션 종료 ( commit/ rollback )
			```

		- 특징:
			선택적으로 임의의 컬럼에 값을 저장할 수 있음
			지정하지 않은 컬럼에는 null 값이 저장됨
			컬럼명이 명시되기 때문에 가독성이 높음
			
		나. 컬럼명 생략

		- 문법:

			```sql
    insert into 테이블명 values ( 값, 값2, .....);
			```

		- 특징:
			선택적으로 컬럼을 지정하지 않기 때문에
			테이블의 실제 생성된 컬럼순서대로 값이 저장됨
			반드시 테이블의 모든 컬럼의 값을 저장해야 됨
			컬럼명이 명시되지 않기 때문에 가독성이 낮음

		다. 주의할점
		- 제약조건을 신경써야 됨
			Primary Key 컬럼은 반드시 값을 가지고 중복되지 않도록 설정
			unique는 유일한 값 저장
			not null 은 반드시 값 저장

4. update 문

	1) 용도
	- 레코드의 컬럼수정

	2) 종류
		가. 조건없는 update 문
		- 모든 레코드의 컬럼이 변경됨

			문법:
		```sql
    update 테이블명
	set 컬럼명=새로운 값, 컬럼명=새로운 값, ,,,,

	
		```

		나. 조건있는 update 문
		- 조건에 맞는 레코드의 컬럼만 변경됨

			문법:
    ```sql
    update 테이블명
	set 컬럼명=새로운 값, 컬럼명=새로운 값, ,,,,
	where 조건식;

ex. 
update my_emp
	set ename='이순신', sal=100,;
	where empno=7369;
    ```

5. delete 문

	1) 용도
	- 레코드 삭제

	2) 종류
		가. 조건없는 delete 문
			문법:

		```sql
		    <- 트랜잭션 시작
	delete from 테이블명;
			<- 트랜잭션 종료 (commit, rollback)

ex. 
	delete from my_emp;
	rollback;
		```

		- 모든 레코드가 삭제
		
		나.  조건있는 delete 문 (일반적으로 사용)

		- 문법:

		    ```sql
delete from 테이블명
where 조건식

ex.
	delete from my_emp
	where empno=7369;
		    ```
		- 조건에 일치하는 레코드만 삭제

6. DDL (Data Definition Language : 데이터 정의어)
	1) 용도
	- 객체 (테이블, 인덱스, 사용자, ...) 생성, 수정, 삭제할 때 사용하는 명령어

	2) 특징
	- DDL은 무조건 자동으로 commit 됨 (rollback 불가)

	3) 테이블 생성 문법
	     ```sql

	create table map
	(empno int primary key,
	...
	deptno int REFERENCES dept(dpetno));
    create table, [IF NOT EXISTS]  테이블명
	( 컬럼명 데이터 타입,
	컬럼명 데이터타입 AUTO INCREMENT, <== 값을 설정하지 않아도 자동으로 증가된 값 저장
	컬럼명 데이터타입 DEFAULT 값, <== INSERT 할때 컬럼명을 지정하지 않으면 NULL 대신 기본값
									ex. writeday date DEFAULT now()
	컬럼명 데이터 타입 제약조건성정 <== NOT NULL|UNIQUE|PRIMARY KEY
	|REFERENCES master 테이블명(master컬럼명) ON DELETE CASCADE|ON DELETE SET NULL
	|CONSTRAINT CHECK (조건식) ex. CONSTRAINT CHECK (컬럼명 in('M','F'))
								 CONSTRAINT  CHECK (컬럼명 in('1학년','2학년','3학년'))
	     ```

	4) 데이터 타입

		가. 수치형
		- 정수형:
			tinyint (1byte)
			smallint (2byte)
			mediumint (3byte)
			int(integer) (4byte)
			bigint (8byte)

		- 실수형:
			float, double

		나. 문자형
		- char(n) : n은 글자갯수 (Oracle에서는 char(4) 의미 ? 4byte)
					고정길이 문자형 처리
			ex. char(4): 영문이든 한글이든 4글자 저장가능

			char(4)로 만들고 'A' 한글자만 저장한다면?

			| |   |    | A |

		- varchar(n): n은 글자갯수 (Oracle에서는 varchar2(n) 의미 ? n byte)
					가변길이 문자형 처리

			varchar(4)로 만들고 'A' 한글자만 저장한다면?
					|A|

			ex. varchar(4) : 영문이든 한글이든 4글자 저장가능

		다. 날짜형
			date: 날짜만 저장, insert 할때 curdate()
			time: 시간만 저장, insert 할때 curtime()
			datetime: 날짜+시간 저장, insert 할때 now()

7. 테이블에 제약조건 설정방법

	1) 테이블 작성하면서 제약조건 설정
		- create 문만 필요

			가. 컬럼레벨
			- 테이블의 컬럼을 설정하면서 제약조건을 같이 설정

			문법:
		    ```sql
    create table NOT EXISTS 테이블명
	(컬럼명 데이터타입 제약조건,
		..
	);
		    ```
			- 5가지 제약조건(Primary key, unique, not null, check, foreign key)
		    ```sql
	ex.
    create table IF NOT EXISTS board
(
	num int PRIMARY KEY AUTO_INCREMENT,
	title varchar(100) NOT NULL, -- 제목
	author varchar(10) unique, -- 작성자
	content varchar(500) NOT NULL, -- 내용
	writeday datetime DEFAULT now(), -- 날짜
	gender char(4),
	readcnt int DEFAULT 0 -- 방문자
);
		    ```
			나. 테이블레벨
			- 테이블의 컬럼들을 모두 설정하고 나중에 제약조건을 설정

			문법:
		    ```sql
    create table NOT EXISTS 테이블명
	(컬럼명 데이터타입,
	컬럼명 데이터타입,
		...,

	제약조건1
	제약조건2
	);
		    ```
			- 5가지 제약조건중에서 not  null  사용 불가
    ```sql
    ex.
    create table IF NOT EXISTS board3
(
	num int AUTO_INCREMENT,
	title varchar(100) NOT NULL , 
	author varchar(10), 
	content varchar(500) NOT NULL, 
	writeday datetime DEFAULT now(),
	gender char(4),
	readcnt int DEFAULT 0,  

	CONSTRAINT PRIMARY KEY(num), 
	CONSTRAINT UNIQUE(author),
	CONSTRAINT CHECK (gender in ('M', 'F'))
);
    ```
	2) 테이블 만든후에 나중에 제약조건 설정

	- create 문 + alter 문 필요
    ```sql
    create table IF NOT EXISTS board4
(
	num int AUTO_INCREMENT,
	title varchar(100), 
	author varchar(10), 
	content varchar(500), 
	writeday datetime DEFAULT now(),
	gender char(4),
	readcnt int DEFAULT 0,
);
    ```

	- alter 문 이요한 제약조건 추가
	
		가. not null 제약조건 변경(modify) 방법
			-문법:
	    ```sql
    alter table 테이블명
	modify 컬럼명 데이터타입 not null;

	ex.
	alter table board4
	modify title varchar(100) not null;

	alter table board4
	modify content varchar(500) not null;
	
	    ```

		나. not null 제외한 나머지 4개 제약조건 추가(add) 방법
			-문법:
	    ```sql
    alter table 테이블명
	add CONSTRAINT 제약조건(컬럼명); -- 테이블 레벨문법과 동일

	ex.
	-- moidfy + add 같이 사용해서 PRIMARY KEY와 AUTO_INCREMENT 한꺼번에 설정
	alter table board4
	add CONSTRAINT PRIMARY KEY(num);

	alter table board4
	add CONSTRAINT UNIQUE(author);

	alter table board4
	add CONSTRAINT CHECK(gender in ('M', 'F'));
	    ```

9. 테이블 삭제 및 절삭
    ```sql
    drop table if exists 테이블명, 테이블명2, ...;

	ex.
	drop table if exists board;
	drop table if exists board2, board3;


	truncate table 테이블명; -- 테이블내의 모든 레코드를 삭제

	* delete vs truncate
	delete : DML -> rollback 가능

	truncate : DDL -> rollback 불가

	ex.
	truncate table my_emp;
	
    ```


10. 테이블 수정

	- 컬럼 추가
    ```sql
    alter table 테이블명
	add column 컬럼명 데이터타입;
    ```
	- 컬럼 삭제
    ```sql
    alter table 테이블명
	drop 컬럼명;
    ```
	- 제약조건 추가
    ```sql
    alter table 테이블명
	modify 컬럼명 데이터타입 not null;
    ```
	- 컬럼이름 변경
    ```sql
    alter table 테이블명
	RENAME COLUMN 컬럼명 TO new컬러명;
    ```

	종합예시
    ```sql
    ex.
	create table if not exists my_dept
	(no int primary key,
	name varchar(10)
	);

-- 컬럼 추가
	alter table my_dept
	add column address varchar(20);

-- 컬럼 변경 (크기 변경)
	alter table my_dept
	modify address varchar(50);

	alter table my_dept
	modify address varchar(10);

-- 컬럼 이름 변경
	alter table my_dept
	RENAME COLUMN address TO addr;

-- 컬럼 삭제
	alter table my_dept
	drop name;
    ```
